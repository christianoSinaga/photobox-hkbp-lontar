Template Preview

Halaman bantu development untuk mengecek koordinat slot dari tim desain. Kotak berwarna = posisi slot menurut JSON. Template dibaca dari /templates/index.json, atau satu template lewat ?t=/templates/nama.json.

Deteksi lubang otomatis

Pilih atau seret PNG bingkai baru ke kotak di bawah. Setiap area transparan dihitung sebagai satu lubang, lalu koordinatnya ditampilkan dan file JSON template dibuat otomatis.
